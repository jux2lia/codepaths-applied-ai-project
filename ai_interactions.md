# AI Collaboration Log

How I used Claude while building this, including where it helped and where it was wrong.

- **Mood column (accepted):** The Kaggle dataset doesn't have a mood column, so Claude suggested guessing mood from valence + energy. Went with it, but the labels are rough. A sad-sounding loud song isn't always "angry."
- **Path planning (revised):** Claude wanted a full graph search. I went with straight-line waypoints instead and let the check/revise loop add bridge songs when a jump is too big. Way easier to build and debug.
- **Using my own playlist (accepted, partly wrong):** Claude said to export with Exportify and match songs to the dataset by track ID, assuming the export wouldn't have audio features. Turns out mine did.
- **Setup (accepted):** Python 3.11 venv, pinned versions, and gitignoring secrets and my personal playlist.
- **Arrival check bug (accepted fix):** Claude's first agent design picked the last song by sound, not genre, so almost every route failed the arrival check and the revise step always made the same fix. It basically looked fake. Now the plan locks in a destination-genre song as the last stop, and revise only handles real problems like big jumps or repeat artists. Routes needing revision went from 26/30 to 9/30.
- **Low match rate (rejected):** Only 6 of my 19 songs matched. Claude suggested switching to the bigger 114k dataset. I kept the 30k one since it was enough and I didn't want to redo the data loading. Downside: no jazz, metal or lofi, so "lofi → metal" became routes like classic rock → big room.
- **Agent jumping to random far songs (accepted fix):** The +2 genre weight from my old scorer was overpowering everything, so the agent jumped across the map. Fix: only score the 50 songs nearest each waypoint, and pick the max step size by testing all 30 destinations (0.12 worked for all of them). Also caught a duplicate "Redbone" with a different track ID.
- **Disney playlist failing (rejected for now):** My Disney playlist got 0% matches because the catalog barely has Disney songs. Claude suggested building the profile straight from the CSV's own audio features. Good idea, but it touches too many files, so it's in future improvements.
- **Chart hiding the route (accepted fix):** Tests passed, but when Claude actually rendered the chart, the route was buried under 28k background dots. Switched to WebGL layers and auto-zoom on the route. Passing tests doesn't mean the chart is readable.
- **Lineage / RAG (revised):** The Steely Dan → "Champion" demo didn't work because neither song is in the dataset. Claude checked famous sample pairs against Wikipedia, and 19 had both songs in the catalog. Sampled songs usually sound pretty different, so the agent can take a bigger step only along a real sample link. New demo is sampled classics → rap, which routes through 2Pac's "Changes" and Kendrick's "King Kunta" with lineage on. Neither shows up with it off.
- **`lineage: nan` bug (caught):** Steps with no sample link were printing `nan` because of a pandas quirk, and it broke one trace's JSON. Fixed it and added a test.
